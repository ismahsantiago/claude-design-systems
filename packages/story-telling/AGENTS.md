# Agent handoff: Story-Telling

When generating a landing page in this directory:

1. Read `DESIGN.md` for the design system and the six-chapter composition.
2. Read `landing-content.md` for the brand-specific copy and real data.
3. Use the compiled `@ds/story-telling` components and the tokens in its
   stylesheet. Wrap the page in `ThemeProvider`.
4. Preserve `[TODO]` and `[SOURCE REQUIRED]`; never fabricate business facts.
5. Keep the page responsive, keyboard accessible, and understandable without
   motion.

The Storybook landing story is a visual fixture. It contains placeholder data
and is not a source of truth for the real brand.
